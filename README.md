# Зарплаты Севера — учебный прототип ФСТШК

## Запуск

Распакуйте весь архив. Для демонстрации дважды нажмите `index.html`. Интернет и установка библиотек не нужны: Bootstrap и Chart.js включены локально. Начальный набор — 2 472 записи за март–июнь 2023 года. Новые записи и изменения цен при таком запуске действуют до перезагрузки страницы.

Для сохранения изменений в SQLite установите Python 3, затем в папке проекта выполните:

```
python -m pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000`. Для остановки сервера нажмите Ctrl+C в терминале. Flask запускается только на этом компьютере, без режима отладки. Это учебный сервер без учётных записей и разграничения прав; публиковать панель изменения данных в интернете нельзя.

## Файлы

- `index.html` — существующая разметка команды: главная, дашборд, вакансии, карточка, калькулятор, отчёт, две вкладки управления.
- `static/styles.css` — цвета, размеры и адаптивность.
- `static/app.js` — навигация, фильтры, единые расчёты, диаграммы, проверки форм и CSV.
- `static/data.js` — локальный снимок исходных вакансий и учебных цен для запуска без сервера.
- `static/vendor` — уже использовавшиеся Bootstrap 5.3.3 и Chart.js 4.4.8, уведомления об их лицензиях.
- `app.py` — сохранённая серверная часть Flask с проверкой вводимых значений.
- `salaries_sever.db` — копия переданной базы; изменение через сервер сохраняется здесь.
- `materials` — шаблон XLSX, макеты PNG, схема навигации и материалы отчёта.

В режиме сервера записи загружаются из SQLite. Автономный снимок `data.js` не обновляется сам после изменений базы: для одинаковой демонстрации используйте один выбранный режим. Все цены набора и базовых городов условные, относятся к учебному сценарию за 2023 год. Их происхождение не подтверждено Росстатом. Набор вместе с арендой не описывает полный бюджет человека; налоговый режим и период оплаты вакансий не подтверждены. Значение индекса: нижняя граница предложения / учебная стоимость набора. Городская медиана вычисляется по имеющимся нижним границам, пропуски исключаются только из зарплатных показателей. Средний набор — простое среднее по городам текущего среза. Общий учебный индекс — медиана нижних границ среза / средний набор, а не среднее городских индексов.

## Что работает

Выбор 2–3 разных городов и периода; поиск по должности и компании на русском; фильтры города и опыта и наличия оплаты; карточка выбранной вакансии; перенос её нижней границы в калькулятор; пересчёт четырёх показателей и четырёх графиков по фильтрам; формирование сводки по датам, городам и опыту; выгрузка именно сформированного результата в CSV; печать текущего экрана; две формы изменения учебных данных. XLSX — отдельный образец шаблона, а не динамический экспорт из браузера. Список вакансий показывает по 100 совпадений на странице; кнопки перехода дают доступ ко всей отфильтрованной выборке.

При отсутствии результатов показано «Нет данных». Неверные даты, отрицательные суммы и обратные границы зарплаты отклоняются. Все пользовательские строки экранируются перед вставкой в таблицу. В исходной базе поле графика частично содержит `close/open`; эти коды показываются как «Не указан», реальный график из них не выводится. Названия компаний также могут быть обезличены в переданных данных.

## Как изменить проект

1. Текст: найдите нужную подпись в `index.html` и замените её. Идентификаторы `id` не меняйте без соответствующей правки JavaScript.
2. Цвета: измените переменные `--primary-color`, `--primary-dark`, `--bg-dark`, `--accent-color` в начале `styles.css`.
3. Данные: для автономного режима отредактируйте массивы в `data.js`, сохранив имена полей и запятые. Для серверного используйте формы управления в браузере; сначала сохраните резервную копию SQLite.
4. Новый экран: скопируйте структуру существующего блока `screen-view`, задайте уникальный `id="screen-example"` и добавьте кнопку `showScreen('example')`. Добавляйте экран только для отдельной пользовательской задачи.
5. Дополнительные фильтры: сначала проверьте, есть ли достоверное поле в данных, затем добавьте условие в соответствующую функцию фильтрации. Не заменяйте неизвестные значения вымышленными.

В собственных HTML/CSS/JS/Python-файлах нет поясняющих комментариев; объяснения находятся здесь. Сторонние библиотеки поставляются в готовом сжатом виде, собственный код не минифицирован. Не редактируйте файлы `vendor` для изменения внешнего вида.

## Проверка

Сценарии автономного прототипа проверены в Edge при 1366×900 и 390×844, макеты находятся в `materials/screens`. Серверные API проверены тестовым клиентом Flask на отдельной копии базы. Соединение браузера с HTTP-сервером в среде проверки не удалось, поэтому полный серверный сценарий в браузере отдельно не подтверждён.
